# 🍸 Sommelier POS - Gastrobar & Restaurant OS

Sistema integral de gestión para bares, lounges, discotecas y restaurantes.

## 🚀 Demo en Vivo
Puedes probar la versión interactiva y ver la presentación oficial en:
👉 **[https://walterdotblend.github.io/koko-demo/](https://walterdotblend.github.io/koko-demo/)**

## ✨ Características Principales
- 🍾 **Control Milimétrico de Botellas**: Seguimiento en tiempo real de mililitros y recetas automáticas de cócteles.
- 📱 **Comandas Móviles para Meseros**: Toma de pedidos desde smartphones con motor de combos automático.
- 💵 **Arqueo Ciego Físico en Soles (S/)**: Conteo honesto de monedas y billetes sin sesgo ni adulteraciones.
- 🗺️ **Plano de Mesas Interactivo**: Estados en vivo con código de colores.
- 📊 **Libro Mayor Financiero**: Auditoría contable inmutable con fotos de comprobantes.
- ☁️ **Modo 100% Offline + Sincronización Supabase**: Operación ininterrumpida ante caídas de internet.
- 🌍 **Soporte Multi-Idioma**: Inglés, Español, Portugués y Francés.
